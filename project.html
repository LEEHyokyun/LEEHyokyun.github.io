GlobalConnect

유학생들을 위한 실시간 커뮤니티 및 네트워킹 플랫폼

GlobalConnect는 유학생들이 정보를 공유하고 네트워킹할 수 있도록 다양한 기능을 제공합니다. React와 Node.js를 기반으로 개발되었으며 주요 기능으로는 게시판, 실시간 채팅, 이벤트 관리 등이 있습니다. MongoDB를 사용하여 데이터를 관리하고, Socket.io를 통해 실시간 통신을 구현하였습니다. 또한 AWS를 이용해 안정적인 호스팅และ 배포를 지원합니다. 팀원들의 협업과 기술적 도전을 통해 완성되었습니다.

Core Features & Implementation

📋 게시판 기능

  • React & Redux를 통한 반응형 UI 컴포넌트 설계 및 상태 관리
  • Axios 기반 RESTful API 통신 (글·댓글 CRUD 및 JWT 권한 검증)
  • MongoDB 스키마 설계를 통한 효율적인 게시글 데이터 적재

💬 실시간 채팅 기능

  • Socket.io 클라이언트-서버 실시간 양방향 이벤트 핸들링
  • 사용자 맞춤형 채팅룸 생성 및 세션 분리 관리
  • 이전 대화 기록 보존을 위한 MongoDB 채팅 로그 연동

Troubleshooting & Optimization

ISSUE 01

데이터베이스 성능 저하 및 서버 응답 지연

🚨 문제 인식

게시판 활성화로 인해 데이터(글·댓글)가 급증하면서, 특정 메인 피드를 불러올 때 쿼리 속도가 급격히 저하되고 서버 응답 시간이 지연되는 현상이 발생했습니다.

✅ 문제 해결 및 성과

자주 조회되는 주요 필드(작성 날짜, 작성자 ID 등)에 복합 인덱스(Compound Index)를 적용하여 검색 속도를 대폭 개선했습니다. 또한 불필요한 필드 조회를 방지하기 위해 프로젝션 쿼리를 최적화했습니다. 이 과정에서 대용량 데이터 관리를 위한 인덱스 설계 원리와 데이터베이스 샤딩(Sharding) 기법에 대한 이해도를 넓혔습니다.

ISSUE 02

동시 접속자 증가에 따른 실시간 채팅 연결 해제 및 지연

🚨 문제 인식

사용자 유입이 몰리는 피크 타임에 Socket.io 소켓 연결이 빈번하게 끊기거나, 메시지 전송 및 수신이 수 초 이상 밀리는 등 사용자 경험을 저해하는 불안정성 문제가 발생했습니다.

✅ 문제 해결 및 성과

서버 로그와 네트워크 트래픽 분석을 바탕으로 단일 인스턴스의 부하 한계를 파악, Socket.io 서버 횡적 확장(Scale-out)을 단행했습니다. 로드 밸런서를 통해 트래픽을 균등하게 분산시켰으며, 메모리 누수를 방지하기 위해 유휴 소켓 연결 및 점유 데이터 복사본을 주기적으로 정리하는 가비지 컬렉팅 로직을 보완하여 안정성을 확보했습니다.
